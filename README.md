Данный проект представляет из себя телефонный справочник.
Для запуска сервера требуеться в качестве параметра передать порт который он будет слушать. ./server 9009 

сервер потдерживает следующий набор команд:
- INSERT name phone type (для добавление контакта) 
- FIND_NAME name (для поиска по имени)
- FIND_PHONE phone (для поиска по номеру)
- SHOW_ALL (показать весь справочник)

На каждую команду сервер должен ответить лмбо OK в случаи успешного выполнения либо ERR в случаи ошибки.
